#  Data Analytics & EDA Projects

This repository contains my professional data analysis projects, focusing on Exploratory Data Analysis (EDA), business trends, customer analytics, and database management. Each project utilizes Python and SQL to extract actionable insights from real world datasets.

---

##  Projects Overview

### 1. E-Commerce Sales Analysis (MySQL Classic Models)
An end to end sales and customer analytics project based on the MySQL Classic Models e-commerce dataset.
* **Key Focus:** Revenue trend analysis, product line performance, customer order behavior, and fulfillment efficiency.
* **Tools & Skills:** MySQL, SQL Queries (`JOIN`s, Aggregations, Grouping), Python (`pandas`, `matplotlib`, `seaborn`).

### 2. Netflix Dataset EDA & Content Analysis
A detailed Exploratory Data Analysis on the global Netflix dataset to uncover content patterns, distribution trends, and viewer preferences.
* **Key Focus:** Content distribution by genre/type (Movies vs. TV Shows), country wise production analysis, rating classifications, and release year trends over time.
* **Tools & Skills:** Python (`pandas`, `numpy`), Data Visualization (`matplotlib`, `seaborn`), Data Cleaning & Preprocessing.

---

##  Technical Stack
* **Languages & Tools:** Python 3.x, SQL, MySQL Workbench, Jupyter Notebook (`.ipynb`)
* **Libraries:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `SQLAlchemy`
* **Core Concepts:** Exploratory Data Analysis (EDA), Relational Databases (RDBMS), Data Cleaning, Trend Visualization
