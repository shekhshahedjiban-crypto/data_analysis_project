#  Netflix Exploratory Data Analysis (EDA)

A comprehensive data analysis project exploring Netflix's content library to uncover key trends in movie vs. TV show offerings, genre distributions, content ratings, and global content production.

---

##  Project Overview

This project analyzes the Netflix dataset to understand how the streaming giant's content catalog has evolved over time. By performing Exploratory Data Analysis (EDA), we extract insights regarding content acquisition patterns, target demographics, top performing genres, and geographic distributions.

---

##  Key Analysis & Objectives

- **Content Ratio Analysis:** Evaluating the proportion of Movies vs. TV Shows in the catalog.
- **Temporal Trends:** Tracking content addition trends over the years to identify peak growth periods.
- **Genre & Category Profiling:** Identifying dominant genres and popular category combinations.
- **Rating & Demographic Analysis:** Mapping content ratings (e.g., TV-MA, PG-13, TV-14) to target audience age groups.
- **Geographic Production:** Analyzing top content producing countries and cross border co productions.

 Getting Started
1. Prerequisites
Ensure you have Python 3.8+ installed on your system.

2. Installation & Setup
Clone the repository:

Bash

cd data_analysis_project/EDA_analysis_netflix_dataset

Bash

Bash

 Key Takeaways
Catalog Composition: Movies make up the majority of total titles, though TV show additions have surged rapidly in recent years.

Dominant Genres: International Movies, Dramas, and Comedies represent the largest shares of the platform's library.

Growth Peak: Content additions experienced exponential growth between 2016 and 2021.
